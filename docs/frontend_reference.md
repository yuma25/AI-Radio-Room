# AI Radio Room フロントエンド・リファレンス

本ドキュメントは、AI Radio Room フロントエンドシステムの全容を言語化したものである。Vite + TypeScript (Vanilla) による「チャットアプリ型」UI の設計思想、データ構造、および処理フローを詳細に解説する。

---

## 1. フロントエンドの処理フロー（全体像）

ユーザーがブラウザでアプリを開き、AI ラジオの放送を開始・視聴するまでの一連の流れを定義する。

### 1.1 初期化フェーズ
ブラウザ起動時の DOM 構築とリソース準備を行う。

1. **エントリポイントの実行**:
    - `src/main.ts` が読み込まれ、`DOMContentLoaded` イベントをトリガーに初期化ロジックが開始される。
2. **UI コンポーネントの構築**:
    - `index.html` 内の `#app` 要素に対し、チャットエリア、サイドバー（設定）、コントロールバー（開始ボタン等）の動的 HTML が注入される。
3. **イベントリスナーの設定**:
    - サイドバーのトグルボタン、放送開始ボタン、各種入力フォームに対するイベントを登録する。

### 1.2 放送・ストリーミングフェーズ
バックエンドから SSE (Server-Sent Events) を受信し、台本をリアルタイムに描画・再生する。

1. **接続確立**:
    - ユーザーが「放送開始」をクリックすると、`EventSource` API を用いて `GET /api/broadcasts/stream` （予定）への接続を開始する。
2. **メッセージ受信**:
    - バックエンドから JSON 形式の `ScriptItem` が届くたびに、受信イベントが発生する。
3. **描画とキューイング**:
    - **描画**: 受信したセリフをチャット吹き出しとしてメッセージエリアに追加し、最下部へ自動スクロールする。
    - **キューイング**: 受信したデータを「音声再生キュー」に追加し、前のセリフの再生終了を待ってから順次 VOICEVOX 音声を再生する（Issue #3 で詳細実装）。
4. **演出適用**:
    - セリフに含まれる `Emotion` 情報に基づき、キャラクターアイコンの表情や背景色を動的に変更する。

## 2. データ定義詳細 (TypeScript)

バックエンドの Go 構造体と整合性を保つための型定義。

### 2.1 AI 連携モデル

#### `Character` 型
- **`role`** [string]: 役割名 (mc, guest-a, guest-b)。
- **`name`** [string]: キャラクター名。
- **`personality`** [string]: 性格設定。
- **`description`** [string]: 役割詳細。

#### `GeneratorConfig` 型
- **`theme`** [string]: 放送テーマ。
- **`characters`** [Character[]]: キャラクター設定の配列。
- **`rules`** [string[]]: 番組ルールの配列。

#### `ScriptItem` 型
- **`speaker`** [string]: 発言者の role。
- **`text`** [string]: セリフ。
- **`emotion`** [string]: 感情 (normal, excited, calm)。

## 3. モジュール構成と役割

- **`src/main.ts`**: 全体のオーケストレーション。各モジュールの初期化とグローバルな状態管理。
- **`src/ui/chat.ts`**: チャット画面の描画、メッセージ追加、スクロール制御。
- **`src/ui/settings.ts`**: 設定サイドバーの表示制御、フォームデータの取得。
- **`src/voice/player.ts`**: VOICEVOX API との通信、音声再生キューの管理（予定）。
- **`src/style.css`**: CSS Variables によるテーマ管理と、Flexbox/Grid を用いたレイアウト定義。
