# AI Radio Room 用語集 (Glossary)

このドキュメントは、プロジェクト内で使用されるアルファベット略称や技術的専門用語の意味を定義し、関係者間で一貫した理解を保つためのものである。

---

## あ行
### インターフェース (Interface)
プログラミングにおいて、構造体が持つべきメソッドの「型」のみを定義したもの。Go では、ある構造体がインターフェースで定義された全メソッドを持っていれば、そのインターフェースを「実装している」とみなされる。

## か行
### 構造体 (Struct)
複数の関連するデータを一つのまとまりとして扱うためのデータ形式。Go におけるオブジェクト指向のような役割を果たす。

## さ行
### シグネチャ (Signature)
関数やメソッドの名前、引数の数や型、戻り値の型の組み合わせのこと。関数の「顔つき」や「定義」を指す。

### ストリーミング (Streaming)
データを一度にすべて送るのではなく、生成された順に逐次送信・処理する手法。本プロジェクトでは、AI のセリフが 1 行できるたびにブラウザへ送る処理を指す。

### SSE (Server-Sent Events)
サーバーからクライアント（ブラウザ）へリアルタイムにデータをプッシュ送信するための技術。通常の HTTP 通信と異なり、接続を維持したまま一方通行でデータを流し続けることができる。

### SPA (Single Page Application)
ページ遷移を行わず、1 つの HTML ページ内で JavaScript（TypeScript）によって表示内容を動的に書き換える Web アプリケーションの形態。

## た行
### 抽象化 (Abstraction)
具体的な実装の詳細を隠し、共通の操作方法だけを外部に見せること。本プロジェクトでは、Gemini API を直接叩くのではなく「台本生成クライアント」として扱うことを指す。

## は行
### バックエンド (Backend)
サーバー側で動作するプログラム。データベース操作や AI API との連携など、ユーザーの目に見えない裏側の処理を担当する。

### フロントエンド (Frontend)
Web ブラウザ上で動作し、ユーザーが直接操作する画面（UI）の部分。

## ま行
### モノレポ (Monorepo)
複数のプロジェクト（例：バックエンドとフロントエンド）を一つの Git リポジトリで一括管理する構成。

---

## アルファベット・記号
### CORS (Cross-Origin Resource Sharing)
異なるドメイン間での通信を制御するブラウザのセキュリティ機能。フロントエンドとバックエンドを別々に動かす開発環境では、これを適切に許可する必要がある。

### NPU (Neural Processing Unit)
AI の計算（ニューラルネットワークの処理）に特化した専用のプロセッサ。

### pnpm
Node.js 用の高速で効率的なパッケージマネージャー。

### UUID (Universally Unique Identifier)
世界中で重複することのない一意な識別子。データベースの主キー（ID）として広く利用される。

### Vite
最新のフロントエンドビルドツール。開発時の起動が非常に速く、プログラムの変更を即座に画面に反映させる機能に優れている。
